# Support
`mailsort` is currently under active development. So there is no commercial support and you use the software at
your own risk. Still the developers are very interested to hear your feedback and continuously work on improving
`mailsort`. Feel free to reach out, ideally via [Github](https://github.com/jan-janssen/mailsort).

If you ran into an error message or a connection problem, check the [Troubleshooting](troubleshooting) page first -
it collects fixes for the issues users hit most often.
